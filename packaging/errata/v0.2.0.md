> **Erratum (v0.2.0, Linux bundle only).** `TEscope-0.2.0-linux-x86_64.tar.gz` was built on a newer build image than documented and requires **glibc ≥ 2.43**, not ≥ 2.39 as these notes state; on older systems (for example Rocky/RHEL 10 or Ubuntu 24.04) it exits at start with a misleading "requires PySide6" message. It was not run on Rocky Linux. The source code, wheel, Windows and macOS builds are unaffected. In addition, in 0.2.0 a project opened in the GUI ran with the default 10-bp bin size instead of the bin size stored in the project file (command-line runs were not affected). **Use v0.2.1**, which corrects both.
