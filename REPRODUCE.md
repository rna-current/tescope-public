# Reproducing TEscope results

Three independent levels, from fastest to most complete.

## 1. Offline acceptance test (synthetic data, ~1 minute)

No network and no reference data needed.

```bash
pip install tescope-0.2.1-py3-none-any.whl
tar xzf tescope-acceptance-pack-0.2.1.tar.gz && cd acceptance-pack
python verify.py          # every canonical table must match its recorded checksum
```

The pack is generated by `examples/make_acceptance_pack.py` from the
synthetic generator used by the test suite; it contains the inputs, the
configurations, and the expected SHA-256 of every output table.

## 2. Test suite (synthetic golden dataset)

```bash
uv sync --extra gui --extra bam
uv run pytest             # unit tests + tests/golden end-to-end numeric snapshot
```

## 3. Real-data example and manuscript figure (public ENCODE data)

See [`examples/h3k9me3_l1hs/README.md`](examples/h3k9me3_l1hs/README.md):
download script with checksums, the exact configurations, the
documented locus-selection criterion, the canonical output tables that
underlie the figure, and the figure capture/composition code.

## Environment

Python ≥ 3.10. Exact dependency versions used for the release builds
are pinned in `uv.lock`. The Linux bundle requires glibc ≥ 2.39; on
older systems use the wheel.
