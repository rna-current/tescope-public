# TEscope User Guide

Complete guide to TEscope **0.2.1**. Three parts, in reading order:

1. **Quick start** (below) — first analysis in five minutes.
2. [**Complete control reference**](reference.md) — every menu item,
   button, field, checkbox, combo choice, mouse gesture, and status
   message of the GUI, screen by screen, with defaults and effects.
   Nothing in the app is undocumented.
3. [**Interpretation concepts**](concepts.md) — what TEscope does vs
   what your upstream pipeline does; raw values vs display
   transforms; SEM vs copy-distribution bands; missing vs zero;
   NH/MAPQ limits; compatibility vs identity; coordinates; offline
   behavior and font portability.

A single-file build of the whole guide (cover + all three parts) is
generated by `assets/build_guide.py` → `TEscope_User_Guide.html` /
`TEscope_User_Guide.pdf` (see *Building the distributable guide*).

## Quick start

### Install

```bash
pip install tescope        # from the wheel / sdist
tescope --help             # CLI present
tescope gui                # desktop app
```

Or use a packaged build (no Python needed): Windows `setup.exe` or
portable zip, macOS `.app` zip (right-click ▸ Open once — unsigned),
Linux `tar.gz` (glibc ≥ 2.39). Details: [`../installation.md`](../installation.md).

### First analysis (GUI)

1. **Reference genome** — pick your assembly (e.g. `hg38`) and press
   **Download annotation** once (network; a one-time per-assembly
   download). Or **Import custom…** with your own RepeatMasker `.out`.
2. **Transposable element** — type a name in the search box (e.g.
   `L1HS`) and select the subfamily **leaf** in the tree.
3. **TE copy filters** — optional; the live counter shows exactly how
   many copies the next run will use.
4. **Signal tracks** — **Add…** (or drag & drop) your bigWig /
   bedGraph / BED / narrowPeak / BAM files. Give replicates the same
   **Group** to plot their mean ± SEM as one series.
5. Press **Run analysis**. The Profile tab shows signal on consensus
   coordinates with a per-bin copy-support panel; Heatmap shows
   per-copy signal; QC records every decision the run made.
6. **File ▸ Save project…** writes one YAML that reproduces
   everything — in the GUI (*Open project…*) or headless:

```bash
tescope run analysis.yaml --out results/
```

A fully offline synthetic walk-through (data + three configs +
expected outputs + verifier) ships as the acceptance pack
(`tescope-acceptance-pack-<ver>.tar.gz`, see its `QUICKSTART.md`).

## Building the distributable guide

```bash
.venv/bin/python docs/user-guide/assets/build_guide.py   # HTML + PDF
```

Rebuild the cover after a version/commit change:

```bash
.venv/bin/python docs/user-guide/assets/make_cover.py
google-chrome --headless --disable-gpu \
  --print-to-pdf=docs/user-guide/assets/cover.pdf \
  --no-pdf-header-footer \
  file://$PWD/docs/user-guide/assets/cover_print.html
```

No documentation build system is introduced: plain Markdown, one
Python script, Chrome headless for the PDF.
